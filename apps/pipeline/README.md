# Pipeline

Data API (`src/server.ts`), CLI (`src/index.ts`), browser exporters, and optional Python tools.

Follow [onboarding](../../ONBOARDING.md), then run `npm run dev:pipeline` from the root. Shared code builds automatically.

Use the [data refresh](../../docs/operations/data-refresh.md) and [photo](../../docs/operations/photos.md) runbooks for operations. `npm test -w yalies-data-pipeline` runs all compiled unit tests.
