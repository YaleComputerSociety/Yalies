Get your Facebook cookie

  1. Open the website below (or in a new tab if the embed is blocked).
  2. Log in if you are not already logged in.
  3. Open your browser developer tools (F12 or Cmd+Shift+I).
  4. Go to the Application tab, then Cookies.
  5. Find the cookie named c_user and copy its value.
  6. Paste the cookie value in the input below and click Validate.
